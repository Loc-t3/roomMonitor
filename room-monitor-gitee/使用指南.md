# 🏠 房间监控程序 - 使用指南

## 一、软件介绍

本程序是一款实时房源监控工具，帮助您在租房旺季快速获知房源释放信息，提高抢房成功率。

### 核心功能
- 🔍 **实时监控**：定时检测目标房源数量变化
- 🔔 **智能提醒**：房间放出时自动弹窗通知
- ⏰ **时段管理**：支持自定义监控时间段
- 💻 **绿色便携**：无需安装，下载即可使用

---

## 二、使用方法

### 3.1 启动程序

**双击运行**

```
直接双击 room-monitor.exe 文件即可启动
```

### 3.2 运行界面

程序启动后会显示控制台窗口，包含以下信息：
```
[INFO] 🏠 房间监控系统启动
[INFO] ✅ 成功获取Cookie
[INFO] 📍 监控配置：
[INFO]    - 上午时段 (12:00-13:30): 深圳市南山区桃源街道平山村353号楼
[INFO]    - 下午时段 (13:33-16:00): 深圳市南山区南头街道中山南街34号
[INFO] ⏱️  请求间隔：5秒
[INFO] ----------------------------------------
```

### 3.3 接收提醒

当检测到房间可用时，会触发两种提醒方式：

1. **控制台提醒**：
```

地址：深圳市南山区南头街道中山南街34号
房间数量：10
检测时间：2026/05/11 15:55:15

==================================================
```

2. **弹窗提醒**：系统会弹出 MessageBox 窗口，确保您不会错过

### 4.1 监控时段

程序会根据当前时间自动切换监控地址：

| 时段 | 时间范围 | 监控地址 |
|------|----------|----------|
