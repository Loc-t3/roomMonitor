# 房间监控系统

## 功能描述

这是一个Node.js前端程序，能够持续请求API获取房间信息，并根据以下规则进行监控：

1. **时间规则**：
   - 12:00 - 13:30：关注"深圳市南山区桃源街道平山村353号楼  (5号线大学城C出口)"
   - 13:55 - 14:30：关注"深圳市南山区南头街道中山南街34号（12号线南头古城站C出口）"

2. **监控规则**：
   - 每15秒发起一次HTTP请求
   - 智能过滤干扰数据，只识别真实的房间数量
   - 当响应体中的`roomNum`大于0时发出提醒
   - 控制台实时显示当前房间数
   - 当房间数量 > 1 时弹出系统通知

## 使用方法

### 1. 安装依赖

```bash
cd room-monitor
npm install
```

### 2. 配置API地址

编辑 `config.js` 文件，修改 `api.url` 为实际的API地址：

```javascript
api: {
  url: 'https://your-api-endpoint.com/rooms', // 替换为你的API地址
  method: 'GET',
  timeout: 10000,
  headers: {
    'Content-Type': 'application/json',
    'User-Agent': 'Mozilla/5.0 (iPhone; CPU iPhone OS 14_0 like Mac OS X) AppleWebKit/605.1.15 (KHTML, like Gecko) Version/14.0 Mobile/15E148 Safari/604.1 MicroMessenger/8.0.2(0x1800022c) NetType/WIFI Language/zh_CN',
    'X-Requested-With': 'XMLHttpRequest'
  }
}
```

### 3. 运行程序

```bash
# Windows
start.bat

# 或手动运行
node index.js
```

## 程序特点

### 智能过滤
- ✅ 过滤用户代理字符串中的干扰数字
- ✅ 只识别包含房间相关上下文的数字
- ✅ 提供详细的解析过程日志（可配置）
- ✅ 当没有真实数据时返回0，避免误报

### 调试功能
通过配置文件可以开启详细日志：

```javascript
// config.js
log: {
  enableTimestamp: true,
  minLogLevel: 'info', // 'debug', 'info', 'warn', 'error'
  enableTrace: true // 启用智能追踪模式
}
```

## 时间配置说明

时间配置使用24小时制，小数点表示分钟：

- `12.5` 表示 12:30（12 + 30/60）
- `13.75` 表示 13:45（13 + 45/60）

在 `config.js` 中可以修改：

```javascript
timeRanges: {
  morning: { start: 12, end: 13.5 },    // 12:00 - 13:30
  afternoon: { start: 13.55, end: 14.5 } // 13:55 - 14:30
}
```

## 注意事项

1. **数据源验证**：确保API地址返回真实的数据
2. **微信环境**：某些API可能需要在微信环境中访问
3. **请求频率**：程序每15秒请求一次，请确保API支持
4. **错误处理**：程序会自动处理网络错误和超时

## 停止程序

按 `Ctrl+C` 停止程序运行。

## 故障排除

### 常见问题

1. **显示没有房间但实际有**
   - 检查API是否返回真实数据
   - 查看调试日志了解解析过程
   - 确认API返回格式正确

2. **被微信环境限制**
   - 程序已内置微信User-Agent
   - 如果仍然受限，可能需要实际微信环境

3. **找不到roomNum**
   - 使用调试模式查看响应结构
   - 检查API是否需要其他参数

## 弹窗通知功能

系统支持弹窗提醒（需要安装node-notifier）：

### 功能特点
- 当房间数量 > 1 时弹出系统通知
- 通知包含地址、房间数量和时间信息  
- 会播放提示声音
- 需要手动关闭通知窗口

### 安装依赖
```bash
npm install node-notifier
```

### 配置方法
在 `config.js` 中启用：
```javascript
alert: {
  enableConsole: true,     // 启用控制台提醒
  enableNotification: true  // 启用系统通知弹窗
}
```

## 扩展功能

如需添加其他提醒方式（如邮件、短信、声音等），可以：

1. 在 `config.js` 中配置相应参数
2. 在程序中的 `alertManager` 添加新的提醒方法
3. 在 `checkRooms` 函数中调用新的提醒方法
